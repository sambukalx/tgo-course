## Окружение

Проверено на Windows, Python 3.13. В GitHub Actions используется Python 3.11, поэтому общий `requirements.txt` не закрепляет пакеты, которые требуют только новую версию Python.

Из корня репозитория в PowerShell:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install torch --index-url https://download.pytorch.org/whl/cpu
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m pip check
.\.venv\Scripts\python.exe -m ipykernel install --prefix .venv --name tgo-course --display-name 'TGO course'
```

На Linux вместо `.\.venv\Scripts\python.exe` используется `.venv/bin/python`. Корпус, модели и данные скачиваются при первом запуске. Интернет для первого запуска нужен; базовые веса и исходные корпуса в Git не добавляются.

## Лабораторные

```powershell
.\.venv\Scripts\python.exe lab01/run.py --download
.\.venv\Scripts\python.exe lab02/run.py
.\.venv\Scripts\python.exe lab03/run.py
```

Вторая работа сохраняет BPE, которым пользуется третья. В `lab02/run.py --fast` только 200 слияний, поэтому перед полным запуском третьей нужен полный BPE из второй. Ключ `--fast` у работ 2–4 предназначен для CI; итоговые отчеты относятся к полным прогонам.

Для четвертой открыть `lab04/train.ipynb`, выбрать ядро окружения и выполнить все ячейки. Либо выполнить его без интерфейса:

```powershell
.\.venv\Scripts\python.exe -m jupyter nbconvert --to notebook --execute --inplace lab04/train.ipynb --ExecutePreprocessor.timeout=-1 --ExecutePreprocessor.kernel_name=tgo-course
.\.venv\Scripts\python.exe lab04/run.py
```

Обучение на CPU занимает существенно больше времени, чем на GPU. На этом компьютере полное обучение выполнялось на Intel Arc 140T: отдельное окружение с PyTorch XPU, базовые веса BF16, микробатч 1, накопление до эффективного батча 8. Сборку XPU можно установить в отдельное окружение, затем поставить остальные зависимости курса:

```powershell
python -m venv .venv-xpu
.\.venv-xpu\Scripts\python.exe -m pip install torch --index-url https://download.pytorch.org/whl/xpu
.\.venv-xpu\Scripts\python.exe -m pip install -r requirements.txt
.\.venv-xpu\Scripts\python.exe -m ipykernel install --prefix .venv-xpu --name tgo-xpu --display-name 'TGO Intel Arc'
```

Нужно выбрать `tgo-xpu` при выполнении ноутбука. Драйвер графики этим способом не обновляется. Для явного выбора CPU: `$env:LAB_DEVICE='cpu'`; для снятия переопределения: `Remove-Item Env:LAB_DEVICE`.

На этом компьютере итоговая оценка выполняется через CPU-окружение `.venv`: длительный XPU-инференс дал нестабильные ответы, хотя обучение завершилось. Сравнение контрольных запусков сохранено в [device_check.json](lab04/artifacts/device_check.json). Для полного CPU-прогона использовались `--batch-size 16 --threads 12`.

Проверка сохраненных результатов:

```powershell
.\.venv\Scripts\python.exe -m unittest lab01.test_bigram lab02.test_bpe lab03.test_model lab04.test_classification
.\.venv\Scripts\python.exe -m pytest tests/test_lab02.py tests/test_lab03.py tests/test_lab04.py -q
```

Официальные тесты взяты из курса без изменений. Пропуски необязательных бонусов не означают, что бонус выполнен. Для первой лабораторной официальных тестов нет.
