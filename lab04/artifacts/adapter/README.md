# LoRA для оценки русскоязычных отзывов

Луценко Вячеслав Александрович, М092501(77). Лабораторная 4 по ТГО.

Адаптер Qwen3-0.6B: оценка от 1 до 5, без генерации рассуждений. Базовые веса не входят в файл.
Ревизия базы: `c1899de289a04d12100db370d81485cdf75e47ca`, данных: `fb29d6137c54550329411023aee45a8ff29f0c62`.
Одна эпоха на 5000 сбалансированных отзывах из train, seed=42, 625 шагов, эффективный батч 8.
LoRA r=8, alpha=16, dropout=0.05, семь проекций q/k/v/o/gate/up/down, lr=2e-4.
Обучено 5,046,272 параметров. Обучение Intel Arc BF16, микробатч 1 с накоплением.

Выполненный ноутбук: `lab04/train.ipynb`. Общий шаблон и обрезка отзыва: `lab04/classification.py`.
Для проверки использовать `python lab04/run.py`: он загружает эту базу и сравнивает zero-shot, few-shot и адаптер.
Полные метрики и ограничения — в `lab04/README.md`; адаптер не является универсальным ассистентом.
