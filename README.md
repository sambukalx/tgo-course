## Запуск первой работы

Для первой лабораторной достаточно Python и стандартной библиотеки:

```powershell
python lab01/run.py --download
python -m unittest discover -s lab01 -p test_bigram.py -v
```

Скрипт выполняет ноутбук и сохраняет выводы ячеек. Корпус загружается
один раз, в Git не добавляется. Если он уже скачан, флаг `--download`
не нужен. В Jupyter можно открыть `lab01/lab01.ipynb` и выполнить все ячейки.

Для следующих работ окружение задано в `requirements.txt`; модели и
наборы данных скачиваются отдельно при первом запуске. Полные результаты
и ограничения описываются в README каждой работы.
