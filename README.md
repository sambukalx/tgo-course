## Запуск

Подробные команды для PowerShell и окружений CPU/Intel XPU — в [ЗАПУСК.md](ЗАПУСК.md). Первая работа использует стандартную библиотеку, для остальных нужны зависимости из `requirements.txt`.

```powershell
python lab01/run.py --download
python lab02/run.py
python lab03/run.py
```

Четвертая обучается через `lab04/train.ipynb`, после этого `python lab04/run.py` выполняет полную оценку. Все сдаваемые ноутбуки уже содержат настоящие выводы, а в `artifacts/` сохранены полные результаты. Флаг `--fast` предназначен для CI и перезаписывает часть результатов сокращенным прогоном.

Курсовая запускается одной командой на CPU:

```powershell
docker compose -p tgo-course -f coursework/docker-compose.yml up --build --wait -d
python coursework/cli.py "Что означает weight decay в AdamW?"
```

Для обучения используются только train-данные, few-shot примеры взяты из validation. Базовые веса, корпуса и рабочие базы не входят в Git. Обученный LoRA-адаптер включен по требованиям задания.
